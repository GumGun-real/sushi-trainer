# Суши — тренажёр меню

Статический мобильный веб-апп для знакомства с меню: каталог с поиском и фильтром категорий, карточки блюд с составом, отметки «Знаю» и «Повторить», а также тест «угадай название по фото». Прогресс хранится локально в браузере.

## Запуск локально

Так как приложение загружает `menu.json` через `fetch`, откройте его через локальный HTTP-сервер, а не двойным щелчком по `index.html`. Например, если установлен Python:

```sh
python -m http.server 8000
```

Затем откройте <http://localhost:8000/sushi-trainer/> (если команда запущена из родительской папки проекта) или <http://localhost:8000/> (если из папки `sushi-trainer`). Сервер нужен только для локальной раздачи файлов; приложение не использует бэкенд.

## Публикация на GitHub Pages

1. Поместите папку `sushi-trainer` в корень репозитория вместе с `index.html`, `style.css`, `app.js`, `menu.json` и папкой `images/`.
2. Отправьте изменения в GitHub.
3. В репозитории откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку (например, `main`) и папку **/(root)**, затем нажмите **Save**.
6. Дождитесь публикации и откройте адрес проекта Pages. Если папка `sushi-trainer` — подкаталог репозитория, страница будет доступна по пути `/sushi-trainer/`.

Пути к файлам относительные (`./menu.json`, `./style.css`, `./app.js`, `images/...`), поэтому проект можно раздавать из подпапки на GitHub Pages.

## Формат меню и изображений

Файл `menu.json` должен содержать объект следующей формы:

```json
{
  "source": "https://example.org/menu",
  "fetchedAt": "2026-01-01T12:00:00Z",
  "items": [
    {
      "id": "unique-id",
      "name": "Название блюда",
      "category": "Роллы",
      "description": "Рис, нори, лосось",
      "price": 500,
      "image": "images/example.webp",
      "sourceUrl": "https://example.org/item",
      "weight": "250 г"
    }
  ]
}
```

Файлы изображений храните локально в `images/*.webp`; укажите относительный путь каждого файла в поле `image`. Запрос меню выполняется при загрузке страницы. Если `menu.json` недоступен или имеет неверный формат, приложение покажет понятное сообщение и кнопку повтора.

## Прогресс и приватность

Отметки сохраняются только в `localStorage` текущего браузера и не передаются на сервер. Если браузер запрещает хранилище или оно переполнено, приложение продолжит работу и покажет предупреждение. Кнопка сброса просит подтверждение перед удалением прогресса.

## Важно

Это **неофициальный тренажёр**, не связанный с рестораном. Фотографии принадлежат ресторану и используются только как локальные материалы тренировки; перед публикацией убедитесь, что у вас есть право распространять изображения.

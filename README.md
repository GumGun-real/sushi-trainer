# Суши — тренажёр меню

Статический мобильный веб-апп для изучения меню «Почтальон суши» (Смоленск): каталог с поиском и фильтром категорий, карточки блюд с составом, отметки «Знаю» / «Повторить», просмотр состава сетов и тренировка «угадай блюдо по ингредиентам». Работает **офлайн** после первого визита, устанавливается на телефон как PWA. Прогресс хранится локально в браузере.

## Быстрый старт локально

Приложение загружает `menu.json` через `fetch`, поэтому открывайте его через локальный HTTP-сервер, а не двойным кликом по `index.html`:

```sh
cd sushi-trainer
python -m http.server 8000
```

Откройте <http://localhost:8000/>. Сервер нужен только для локальной раздачи файлов — бэкенда нет.

## Публикация на GitHub Pages

1. Убедитесь, что в корне репозитория лежат файлы `index.html`, `style.css`, `app.js`, `menu.json`, `manifest.json`, `sw.js` и папка `images/` (или разместите всё это в подпапке — все пути относительные).
2. Закоммитьте и запушьте изменения:
   ```sh
   git add .
   git commit -m "Тренажёр меню: офлайн-режим и PWA"
   git push
   ```
3. В репозитории на GitHub откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку **/(root)** (или `/docs`, если файлы там) → **Save**.
6. Через пару минут откройте выданный адрес `https://<user>.github.io/<repo>/`. Если файлы в подпапке — адрес будет включать её путь.

> Важно: GitHub Pages раздаёт по HTTPS, а Service Worker (`sw.js`) требует защищённого контекста — на Pages это выполняется автоматически. На `http://localhost` SW тоже работает.

## Установка на телефон (PWA)

1. Откройте адрес Pages в браузере телефона (Chrome на Android, Safari на iPhone).
2. Android/Chrome: меню ⋮ → **«Установить приложение»** или **«Добавить на главный экран»**.
3. iPhone/Safari: кнопка «Поделиться» → **«На экран Домой»**.
4. После первого визита приложение работает **без интернета**: меню и все фото закэшируются Service Worker'ом.

## Офлайн-режим

- `sw.js` при первой загрузке кэширует `index.html`, `style.css`, `app.js`, `menu.json`, `manifest.json`.
- Картинки из `images/` кэшируются «лениво» при просмотре (стратегия cache-first с докачкой в кэш).
- При обновлении сайта поднимите версию кэша в `sw.js` (`sushi-trainer-v2` и т.д.) — старый кэш автоматически удалится.

## Структура проекта

```
sushi-trainer/
├── index.html      # каркас приложения
├── style.css       # стили
├── app.js          # логика: каталог, сеты, викторина, прогресс
├── menu.json       # данные меню (спарсено с сайта ресторана)
├── manifest.json   # PWA-манифест
├── sw.js           # Service Worker (офлайн)
└── images/         # локальные фото блюд (webp)
```

## Прогресс и приватность

Отметки «Знаю» / «Повторить» хранятся только в `localStorage` вашего браузера и никуда не отправляются. Кнопка «Сбросить прогресс» просит подтверждение.

## Важно

Это **неофициальный тренажёр**, не связанный с рестораном. Фотографии принадлежат ресторану; перед публикацией убедитесь, что у вас есть право их распространять. Автор не собирает данные пользователей.

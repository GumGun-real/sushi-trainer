# Суши — тренажёр меню

Статический мобильный веб-апп для изучения меню «Почтальон суши» (Смоленск): каталог с поиском и фильтром категорий, карточки блюд с составом, отметки «Знаю» / «Повторить», просмотр состава сетов и тренировка «угадай блюдо по ингредиентам». Работает **офлайн** после первого визита, устанавливается на телефон как PWA. Прогресс хранится локально в браузере.


## Структура проекта

```
sushi-trainer/
├── index.html      # каркас приложения
├── style.css       # стили
├── app.js          # логика: каталог, сеты, викторина, прогресс
├── menu.json       # данные меню (спарсено с сайта ресторана)
├── manifest.json   # PWA-манифест
├── sw.js           # Service Worker (офлайн)
└── images/         # локальные фото блюд (webp)
```

## Прогресс и приватность

Отметки «Знаю» / «Повторить» хранятся только в `localStorage` вашего браузера и никуда не отправляются. Кнопка «Сбросить прогресс» просит подтверждение.

## Важно

Это **неофициальный тренажёр**, не связанный с рестораном. Фотографии принадлежат ресторану; перед публикацией убедитесь, что у вас есть право их распространять. Автор не собирает данные пользователей.
